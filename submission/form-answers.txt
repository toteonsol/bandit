One-line pitch:
BANDIT is the first agent that prices airdrop points: it tells you what each point on a Pendle YT actually costs you, and its agent farms the cheapest ones automatically on Robinhood Chain, acting only when SERV Reasoning agrees.

Description:
People buy Pendle YTs to farm points for future airdrops, but nobody tells them what a point costs. BANDIT turns YT leverage, the points multiplier and time decay into one number, cost per 1,000 points, and ranks every liquid Pendle market by it. It also places each implied APY in its own 90-day band (P12 means only 12% of days were lower) and flags distorted markets (thin, near expiry, extreme APY) so they never get ranked. Robinhood Chain markets come first, including tokenized NVDA, PFE and SGOV. Pendle publishes no points rate for them, so BANDIT labels them speculative airdrop plays instead of inventing a number.

On top of the data sits an autonomous agent on Robinhood Chain. You set a band rule (enter or exit when a band percentile crosses a level) or Farm mode (buy the cheapest points under your max cost, skip the top 20% of each band, rotate near maturity). A watcher checks every 10 minutes. On a trigger it gets a live Pendle quote, and SERV Reasoning must confirm with a written reason. Only then does the agent trade from its own wallet, with hard caps in code ($25 per trade, $100 per day, 5% maximum price impact, an allowlist, and a kill switch), simulating every transaction first. Telegram gets the points math and the reason, and a receipts page links every trade to the Robinhood Chain explorer with a points ledger. The Agent Live view animates each run step by step.

Anyone can use it without a wallet: the Farm board, Ask BANDIT, and Telegram alerts. Reviewers can also trade with their own Rabby or MetaMask: BANDIT builds the trade, SERV reviews it, and they sign. Data and reasoning only, not financial advice.

How it uses SERV:
SERV Reasoning is the decision layer, called through the OpenAI SDK at inference-api.openserv.ai/v1 (model gpt-5.4-mini) with strict json_schema output.
1) Risk gate: before the agent acts on a rule, or before a user signs, SERV weighs band position, cost per 1,000 points, decay, liquidity and the live Pendle price impact, then returns confirm or reject with a plain-language reason. Only a confirmed trigger proceeds, and the code still enforces the hard caps on top.
2) Ask BANDIT: a ranked read for the user's size, goal (farm points, fixed rate, balanced) and risk level, with the points math and main risks for each market.
3) Alerts: a short SERV read attached to every Telegram alert.
There is no fallback model. If SERV fails, the agent does nothing and the UI says so.

Why it has revenue potential:
Points farming is one of the biggest reasons people buy YT, and there is no tool that prices a point. BANDIT does it for free on the board, then monetizes the agent. A Pro tier adds more rules, faster checks, more markets and chains, and custom band thresholds, plus an optional small fee per agent trade. The next step is agent accounts for every user: a smart account per user (email or passkey login) with a session key capped by that user's limits, so anyone can run their own points agent without BANDIT holding their funds. SERV keeps the reasoning cheap enough to run on every trigger.
