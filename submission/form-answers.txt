One-line pitch:
BANDIT places every live Pendle market inside its own 90-day yield band, and SERV Reasoning explains where each one sits and what the trade-offs are for your size and risk.

Description:
BANDIT is a yield-band agent for Pendle PT and YT markets. It pulls live implied APY for every liquid Pendle market on Ethereum and Arbitrum, computes each market's 90-day band (lowest to highest daily implied APY), and places today's rate inside it as a percentile, for example "P12 of its 90-day band, near floor". The band board ranks markets by band position, with days to maturity, liquidity, underlying APY and the 7-day change. The Ask BANDIT box takes a position size and a risk level (low, medium, high) plus an optional question, and SERV Reasoning returns a ranked read of the best-fitting markets, the reasoning for each, and the main risks: time decay near maturity, thin liquidity, and bands that are still forming. Data and reasoning only, not financial advice.

How it uses SERV:
Every Ask BANDIT answer is generated by SERV Reasoning. A serverless function calls the SERV endpoint (inference-api.openserv.ai/v1) through the OpenAI SDK with model gpt-5.4-mini. It sends the user's inputs plus the top 20 markets' band data as structured JSON, under a fixed system prompt that defines how to read a band, how to rank for each risk level, and strict wording rules. SERV returns strict JSON through a json_schema response format, which BANDIT renders as ranked market cards next to each market's live band gauge. The SERV key stays server side, and there is no fallback model: if SERV fails, the UI says so.

Why it has revenue potential:
Band position is the question every PT and YT holder asks before sizing in: is this rate near its floor or its top? BANDIT answers it for free on the board and monetizes with a Pro tier: alerts when a market crosses a band threshold you set (for example P10 or P90), custom band thresholds and windows, portfolio-aware Ask BANDIT sessions that remember your positions, and more chains and venues. Yield traders already pay for alerting and analytics tools, and SERV makes the reasoning layer cheap enough to run per user.
